# 格式：``<仓库相对路径>\t<违规码>\t<原因>``
#   · 违规码 E2 = 文件不能整体按 UTF-8 解码；E1 = mojibake；E4 = 缺 encoding
#   · 只写两列（``<路径>\t<原因>``）= 该路径的**所有**码都豁免
#
# ★ 这些条目**不是**本项目的乱码缺陷，而是**上游原生**的文件编码：
#   kamailio 是 2000 年代的老代码库，源码/测试/文档里大量 latin-1 注释与作者名。
#   ⇒ 「无法确定原文」（多数是 latin-1 注释，转成 UTF-8 会偏离上游原貌）
#   ⇒ **不修改**，只登记；RFC 抽取路径（kb/<协议>/spec/）不含这些文件 ⇒ 不影响语料。
#
