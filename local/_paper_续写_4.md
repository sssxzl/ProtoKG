# 4 面向种子生成的多源知识检索增强与种子生成方法

针对第 1 节提出的第二个挑战，本章阐述面向种子生成任务的检索增强与种子生成方法。与将协议知识一次性全部输入大语言模型的朴素做法不同，本章方法根据具体生成任务从知识中枢中精准检索相关知识，构建分层增强上下文，并在封闭式校验的约束下引导大语言模型生成满足协议结构与交互约束的种子，最后通过迭代修正机制保证种子质量。本章对应第 3.1 节的第三、四阶段，即多源知识检索增强与 LLM 驱动的协议种子生成。

## 4.1 方法概述

从知识中枢到初始种子语料库的生成过程可概括为四个环节：**知识检索、上下文构造、种子生成与种子校验**。给定目标协议、待生成消息类型与当前交互上下文，方法首先从知识中枢中检索与本次生成任务相关的知识原子集合；随后将检索所得知识按维度组织为分层的增强上下文；继而以增强上下文为提示引导大语言模型生成候选种子；最后依据知识中枢中的协议知识对候选种子进行封闭式校验，校验未通过者触发迭代修正，直至种子合法或达到迭代上界。经校验通过的种子被写入种子语料库，供后续变异式模糊测试使用。

## 4.2 面向种子生成的知识检索

知识中枢中的知识以知识原子为单元、以引用与嵌套关系为边构成结构化知识图谱。基于这一结构化特性，本文采用**图原生导航（graph-native navigation）**的检索方式，而无需向量索引。针对不同规模的目标协议，提供两种检索策略。

**策略一：全量分桶。** 对于知识原子总量较小的协议，将知识中枢中的全部知识原子按方面（Aspect）分桶，组织为面向种子生成的结构化知识集合，具体包括：方法清单及其改状态属性、状态转移表、各方法的必填头部字段、头部字段取值池、安全关注（源于历史漏洞）等。分桶所得即为种子生成所需的全部知识。

**策略二：k 跳子图检索。** 对于知识原子总量较大的协议，为避免上下文冗余，从目标方法与目标状态出发，在知识图谱上进行 k 跳广度优先检索，仅取回与本次生成目标相关的子图。检索沿两类边展开：方法节点连接其必填头部字段与转移两端的状态节点，状态节点连接以其为起点的转移与相应方法节点。无显式目标时退化为全量分桶。

（图 4-2 知识分桶与 k 跳子图检索示意图。插入位置：4.2 节末尾。图示内容：左侧为按方面分桶得到的结构化知识集合；右侧为从目标方法/状态出发的 k 跳子图检索过程，虚线标出检索边界。）

## 4.3 增强上下文构造

检索所得的知识原子集合需进一步组织为可供大语言模型消费的增强上下文。本文将分桶所得的结构化知识按维度渲染为若干知识区段，包括协议方法区段、状态机转移区段、必填字段区段、字段取值池区段与安全关注区段，并与本次生成目标（目标协议、待覆盖状态路径、目标方法与漏洞关注）共同构成提示上下文。通过将消息级语法要求与会话级状态要求分层组织、联合提供，增强上下文既保证了字段层面的合法性约束，又保证了交互顺序层面的状态约束。

## 4.4 LLM 驱动的种子生成

本文以大语言模型为生成器，在增强上下文的引导下生成候选种子。一个会话种子由有序的消息序列构成，每条消息包含方法、头部字段与消息体，并携带其对应的统一资源定位符；种子整体还记录其拟覆盖的状态路径、目标方法与生成来源。为生成候选种子，方法将增强上下文中的协议方法、状态转移、必填字段、取值池与安全关注等信息与明确的生成要求一并提供给大语言模型，要求其输出结构化的种子集合。生成要求中显式约束：方法必须来自知识区段中的方法清单，状态转移必须符合状态机区段，必填字段不得缺失，取值优先取自取值池，数值字段采用边界取值，且不同种子应尽量覆盖不同的目标资源以提升多样性。

## 4.5 种子校验与 ReAct 迭代修正

为抑制大语言模型生成结果中的幻觉与不一致，本文对候选种子施加基于知识中枢的封闭式校验，校验维度包括：方法白名单校验（消息所用方法必须属于知识中枢中的方法清单）、必填字段校验（各方法必须携带其必填头部字段）与状态转移校验（消息序列必须符合知识中枢中的状态机转移关系）。校验未通过的种子触发 ReAct 迭代修正：将校验错误信息反馈至生成环节，引导大语言模型针对性地修正种子后重新生成，直至全部种子通过校验或达到预设的迭代上界。迭代修正机制使种子生成过程具备自校正能力，在保留大语言模型生成多样性的同时，保证了输出种子的协议合法性。

## 4.6 种子语料库输出

通过校验的种子按目标模糊测试工具的输入格式落盘，形成初始种子语料库。以 ProFuzzBench 兼容的 .raw 格式为例，种子中的消息序列被渲染为请求行与头部字段组成的文本报文；消息级统一资源定位符与运行时占位符在落盘时替换为实际取值。此外，本文保留了一个确定性的桩生成器（Stub LLM Client）作为大语言模型的降级实现，使整个种子生成流水线可在不依赖真实大语言模型的情况下进行确定性测试。至此，从多源知识抽取到初始种子语料库输出的端到端流水线构建完成。
