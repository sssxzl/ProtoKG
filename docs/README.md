## 命名约定

- **中文命名**：说明性文档一律中文名（2026-11-09 统一）
- **不带版本号**：文件名只用「目前版本」（`v1`/`v2` 等一律不用；历史版本**删除**而非保留）
- **不带日期后缀**：日期写在文档头部，不写进文件名
- **图**：`docs/图/` 下集中放 Mermaid；`种子生成类图.mermaid` 已标注**过时**（描述的是已清理的 RQ3 实验层类）
