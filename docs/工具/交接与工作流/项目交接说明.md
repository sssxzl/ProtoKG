## Authority Rule

`docs/工具/交接与工作流/项目交接说明.md` 是项目恢复 / 状态导航真源，不是 normative contract 真源。

**权威分层**：

1. **Final Frozen Contract + explicitly COMMITTED amendments / errata** = normative semantic / design authority
2. **Canonical Machine Asset** = current implementation-state authority
3. **项目交接说明.md** = resume navigation only

**冲突处置**：

**A.** 若 Canonical Machine Asset 与 Final Frozen base text 存在差异，但该差异已经被明确的 COMMITTED amendment / errata 授权，且 machine state 与该 amendment 一致：

→ 不视为 repository inconsistency
→ 以 **Final Frozen base contract + committed amendment / errata** 作为完整 normative authority

**B.** 若 Final Frozen Contract / committed amendment / Canonical Machine Asset 之间存在未登记、未解释或相互矛盾的差异：

→ repository inconsistency
→ 不得自动选边
→ STOP
→ contract / machine reconciliation

**C.** 上述 normative / machine authority 均优先于 Handoff 摘要。

**D.** Handoff 出错时修 Handoff。不得反向修改 Frozen Contract / Committed Amendment / Canonical Machine Asset 以迎合 Handoff。
