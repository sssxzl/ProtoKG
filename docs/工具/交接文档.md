## 5. 踩坑清单（绝对不要踩）

### 5.1 环境坑（每轮都会踩）

- **pytest 必须用 `E:/app/Anaconda3/python.exe`**（3.13.9）。默认 `python` 是 WorkBuddy 自带 3.13.12，**没装 pytest**。
- **Edit 工具在 CRLF 文件上多行匹配不稳**（报 "not found"）⇒ 对 CRLF 源文件用
  「`read_bytes` → 唯一匹配断言（旧文本恰好出现 1 次）→ `write_bytes`」的 Python 补丁脚本。补丁错一个字会 count=0 **静默不生效**。
- **改 profile 开关做 OFF/ON 对照**：`json.dumps` 重写整个 JSON 会重排全文件、破坏 mtime+MD5 护栏
  ⇒ 用**外科式替换单个 token**（保行尾），跑完**无条件还原 + 断言还原成功**。已踩 3 次「读到旧产物」。
- **QA 目录下的实验产物会被外部清掉** ⇒ OFF/ON 对照必须在**同一条 bash 命令内**跑完并立即比对。
- **护栏期望集**：真实比对文件是 `expected_b_class_failed_ids.txt`（32 条），
  **不是** `ci_expected_failed_ids.txt`（63 条）—— 拿错会误判「新增 4 条」。
- **pytest `-r` 是覆盖语义** ⇒ 写 `-rfE`（不能写 `-rf -rE`），否则 FAILED 行不输出。
- **GitHub 推送**（已踩多次）：
  ```bash
  TOK=$(grep -v "^#" ~/.github_token | head -1)
  AUTH=$(printf 'sssxzl:%s' "$TOK" | base64 | tr -d '\r\n')
  git -c "http.extraHeader=Authorization: Basic $AUTH" push origin main
  ```
  要点：`$AUTH` 必须是 `base64("账号:令牌")`；裸 PAT ⇒ HTTP 400、`Bearer` ⇒ 401；
  `base64 -w0` 在本机也可用，但 `tr -d '\r\n'` 更保险。
  令牌在 `~/.github_token`（`grep -v "^#" | head -1`，**别用 `head -1`**，前面有注释行）。
  令牌曾明文暴露过，**待用户轮换**。

### 5.2 编码坑

- 第三方 `kb/` 文件拷贝时被 latin-1/cp1252 误读再 UTF-8 写出 ⇒ **双重编码 mojibake**，
  还原用 cp1252 优先、latin-1 兜底的迭代往返；上游原生 latin-1 的**登记豁免、不臆测替换**。
- 给 `open()` 补 `encoding="utf-8"` 用 **AST 字节偏移**（`ast.parse(bytes)` 的 `end_col_offset`
  是 UTF-8 字节偏移，闭合括号位置是 `end_col_offset - 1`），写盘前再 `ast.parse(out)` 验证语法。
- 编码护栏：`guard/verify_encoding.py`（可 `--fix`），检查 E1 mojibake / E2 非法 UTF-8 /
  E3 混合行尾 / E4 缺 encoding；豁免登记 `guard/baseline/encoding_known_issues.txt`。

### 5.3 结构性教训（批次 1/1.6 沉淀，别重踩）

- **⑤ 层后处理链必须收敛在 `_postprocess_action_seq_seeds()` 一个函数里** —— 分散调用已经漏了两次。
- **插 prologue 后的 CSeq 用「平移」`_shift_cseq_by_one`，不能「重排」`_renumber_cseq`**（重排抹掉 cseq-replay 变异）。
- **文件名编号宽度按「基准层条数」算**（`base_count`），⑤ 层另用 `M` 前缀独立编号。
- **闸门报告同时给绝对数 + 比率，并按层拆分**。
- **「bundle 内容一致」≠「产物逐字节不变」**：methods/headers 是 dict，键插入序取决于 fact 遍历序 ⇒
  校验 bundle **禁用 `sort_keys=True`**，必须同时断言「视图遍历序 + dict 键序 + 端到端 .raw MD5」。
- `action_seq.py` 的 **`ledger` 是必传**，新增调用方必须显式给台账。

### 5.5 其它结论（决策依据，别重复论证）

- `corpus_gate` 的 G5 只查「基准层」条数（`scope="base-layers-only"`）⇒ ⑤ 层纯追加不会掩盖契约漂移。
- ⑤ 层产出被**底料量**主导（规则集不是瓶颈，底料量才是）。
- ⑤ 层当前主力规则是 `value-pool-boundary` 与 `cseq-replay`，不是 `missing-required-header`。
- **绝不在主工作树做批量删除**：`kb/` 第三方源码带只读位，`rm -rf` 会 Permission denied 且 `set -e`
  中途退出 ⇒ 工作树被删空。建快照用 `git worktree add`；清只读位用 PowerShell `IsReadOnly=$false`。
