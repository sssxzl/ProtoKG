## 三个需裁定的点

1. ★ **拆分与合并不可同时成立为 Gold**。★ A 将 SHOULD 与 SHOULD NOT 分立两条（理由为避免一条记录内极性混杂）；★ B 合为一条且仅标 negative 极性。
2. ★ **候选 ID 归属须一并裁定**。★ AU-04、AU-05 在 A 名下挂 H3-16、B 名下挂 H3-15。
3. ★ **AU-02 仅 A 提出**。★ 落在 H3-13 跨度 371-374 内，★ 而 H3-13 候选只覆盖第 371-372 行，★ 需判定 accepted 或 excluded。
