## 一、★ 源证据定位修复（★ 两个阻塞之一）

### 1.1 ★ 你的指正完全正确：★ **span 不能一律当绝对行号**

★ N1-R 曾把 `span` 一律当绝对行号（★ 依据是「`chunk_start + span` 越界」）⇒ ⇒ **★ 该推断错误**：
★ `chunk_start + span` 越界只说明「该换算不成立」，★ **不能推出 span 是绝对行号**。

⇒ ⇒ ★ **本版改为直接复用 M1-Q2 的 `resolve_span_evidence` 契约**（★ 不再自造换算）：
① **绝对优先**（`entity_in_span` ±3 命中）② 未命中才试相对 = `chunk_start + (raw_span - 1)`
③ 相对结果须落在 chunk 内 ④ 两者都命中 ⇒ 歧义不放行

### 1.2 ★★ 两个被点名的案例（★ 修复前后）
