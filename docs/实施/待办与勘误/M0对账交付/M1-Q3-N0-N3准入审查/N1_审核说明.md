## 三、★ 双阶段盲审流程

```
阶段一（盲审）        阶段二（冻结）          阶段三（汇总）
A 独立填 A:*  ┐
                ├→ 冻结标签 ──→ 读取模型状态 ──→ 计算误确认/误拒收/精确率
B 独立填 B:*  ┘   （分歧仲裁）
```

| 规则 | 说明 |
|---|---|
| ★ **盲审文件** | `N1_盲审标注表_A.csv` 与 `N1_盲审标注表_B.csv`（★ 同一批 50 条，★ 各自完整标签列） |
| ★ **第二审核者** | ★ **必须有完整独立标签**（★ 9 个标签列，★ **非仅姓名列**） |
| ★ **模型状态** | ★ **不在人工文件中**；★ 单独存放，★ 汇总阶段才读取 |
| ★ **分歧仲裁** | ★ `N1_仲裁表.csv`；★ **仲裁后以仲裁结论为准** |
| ★ **K 组优先** | ★ K 组（20 条风险富集）**优先安排双人独立审核** |

## 四、标注字段与枚举

| 字段 | 取值 / 说明 |
|---|---|
| `subject` | ★ 义务承担者；★ **指代须写出解析后的实际承担者**（★ 如「This field」→「CSeq」） |
| `action` | ★ 行为动词 |
| `object` | ★ 行为对象（★ 跨行须完整） |
| `strength` | ★ MUST / MUST NOT / SHALL / SHOULD / SHOULD NOT / MAY / REQUIRED / RECOMMENDED / … |
| `polarity` | ★ positive / negative（★ SHOULD NOT ⇒ **negative + strength=SHOULD**） |
| `condition` | ★ **原文中的条件**；★ 无则 `null`；★ ★ **不得**填整条 constraint |
| `exception` | ★ 原文中的例外；★ 无则 `null`（★ 原始候选**无 exception 字段**） |
| `evidence_support` | ★ supported / partially_supported / contradicted / **evidence_insufficient** |
| `final_label` | ★ valid_confirmed / valid_rejection / **false_rejection** / **false_confirmation** / pending_insufficient_evidence / uncertain_requires_human |

★ ★ **允许并鼓励 `evidence_insufficient`**：★ 大量落在此值 ⇒ 说明**候选本身缺少必要字段证据**
（★ 而不是审核者不努力）——★ 这本身是重要的质量信号
