## 二、★ 证据定位（★ 按 M1-Q2 契约）

| 列 | 含义 |
|---|---|
| `★ raw_span` | ★ 冻结件原始行号（★ 口径由契约决定，★ **不假定是绝对或相对**） |
| `★ resolved_span` | ★ **按契约解析**后的锚点行 |
| `★ span_mode` | ★ `absolute` / `relative` / `not_found` / `out_of_range` |
| `★ within_chunk` | ★ 锚点是否落在 chunk 内 |
| `★ matched_evidence_lines` | ★ entity 首次匹配行 |
| `★ 锚点行原文（★ 合法可为空）` | ★ 锚点行原文（★ **可为空**） |
| `★ 锚点行是否空白` | ★ 显式标记 |
| `★ 证据句（含 entity 的非空行）` | ★ **±3 内含 entity 的非空行**（★ 锚点空白时的证据载体） |
| `★ RFC 原文上下文（锚点 ±6 行）` | ★ 同版本 RFC 原文 |

★ ⇒ **若 `span_mode` 为 `not_found` / `out_of_range`，该候选不会出现在本包中**
⇒ ⇒ **本包 50 条全部完成有效证据定位**

## 三、★ 盲审十项（★ 只填这些）

| # | 列 | 说明 |
|---|---|---|
| 1-7 | `★ A:subject` / `action` / `object` / `strength` / `polarity` / `condition` / `exception` | ★ **主体、动作、对象、强度、极性、条件、例外**（★ `condition` / `exception` 无则 `null`） |
| 8 | `★ A:evidence_support` | ★ **原文支持程度**：`supported` / `partially_supported` / `contradicted` / **`evidence_insufficient`** |
| 9 | `★ A:truth_label` | ★ **独立语义真值**：`valid_confirmed` / `valid_rejection` / `pending_insufficient_evidence` / `uncertain_requires_human` |
| 10 | `★ A:review_note` | ★ **独立审核理由** |

★ ★ **枚举中不含 `false_confirmation` / `false_rejection`**
★ ⇒ ★ **这两个标签由汇总脚本结合隐藏的模型状态自动生成**（★ **请不要自己判断它们**）

★ ★ **无法判断时**：★ `evidence_support` 填 `evidence_insufficient`，★ `truth_label` 填
`pending_insufficient_evidence`，★ `review_note` 写明缺什么证据
