# R4A XLSX 单元格保全回归报告

## 一、已验证事实

### 1.1 格式规范落实

| 规范 | 实现 | 校验结果 |
|---|---|---|
| 四表结构 | 说明 / 机器身份 / 人工审核 / 补充知识 | ✔ 仲裁表用独立的说明加仲裁记录结构 |
| A/B 机器身份完全一致 | 同一构建函数生成 | ✔ 差异单元格 0，文件哈希相同 |
| 行号、跨度、ID 强制文本 | `number_format='@'` 加字符串写入 | ✔ |
| 机器字段锁定，人工区解锁 | 单元格 `Protection(locked=True/False)` 加工作表保护 | ✔ |
| 合法枚举与数据验证 | 隐藏枚举表加命名区域 | ✔ 人工审核 9 项、仲裁 4 项下拉 |
| 支持一候选多条原子知识 | 补充知识表，每候选 2 行空位 | ✔ |
| 保存重开后逐单元格验证 | 构建函数内置重开比对 | ✔ 差异 0 |
| SHA256 与机器基线一致性 | `R4A_审核ID映射与版本哈希.json` | ✔ |
| 不用 CSV 作主文件 | 全部为 .xlsx | ✔ |
| Agent 不填人工结论 | 人工列全部为空 | ✔ |

### 1.2 特殊字符保护

文本单元格写入时设置 `data_type='s'` 与 `quotePrefix=True`，避免公式样式字符串被解析。候选命题、证据引文与原文中的引号、换行、`⏎` 保持原样。

## 二、限制

1. 校验由构建脚本在同一进程内执行，覆盖重开读取路径，但未模拟 Excel 的完整渲染行为。
2. 文件哈希包含 zip 条目时间戳，两次构建可能不同。审计以机器基线 JSONL 的哈希为准。
