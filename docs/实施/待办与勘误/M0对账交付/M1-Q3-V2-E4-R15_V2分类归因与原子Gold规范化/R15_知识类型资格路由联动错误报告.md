# R15 知识类型、资格与路由的联动错误报告

> ★ 基于 R14 首次冻结评估的逐条对账 ｜★ R14 结果保持冻结

---

## 一、已验证事实

### 1.1 三项错误计数

| 指标 | 错误记录数 |
|---|---:|
| 知识类型 | 39 |
| 规则资格 | 28 |
| 目标路由 | 39 |
| **跨指标累计** | **106** |
| **★ 含错误��唯一候选** | **39** |

★ 106 是跨指标错误记录数，★ **不是 106 条独立候选**。★ 三项指标在同一候选上可同时出错。

### 1.2 联动关系

| 关系 | 条数 | 说明 |
|---|---:|---|
| 类型错 ⇒ 路由错 | 39 | ★ 类型与路由是确定性映射，★ 57/57 条匹配状态一致 |
| 类型与资格对、★ 但路由错 | 11 | ★ 类型与资格均正确时路由仍可能不同 |

### 1.3 类型与路由的确定性映射

| Gold 类型 | Gold 路由 | 机器预测类型 | 机器预测路由 |
|---|---|---|---|
| normative_rule_candidate | rule_channel | normative_rule_candidate | rule_channel |
| protocol_descriptive_semantics | descriptive_channel | protocol_descriptive_semantics | descriptive_channel |
| protocol_syntax | structured_channel | protocol_syntax | structured_channel |
| protocol_registry_or_enumeration | structured_channel | protocol_registry_or_enumeration | structured_channel |
| non_protocol_metadata | metadata_channel | non_protocol_metadata | metadata_channel |
| mixed_or_uncertain | pending_review | mixed_or_uncertain | pending_review |

★ 两侧均为确定性映射，★ 因此**类型准确率与路由准确率在数学上恒等**
（★ R14 实测：SIP 33.33% = 33.33%，★ RTSP 28.57% = 28.57%，★ SMTP 30.43% = 30.43%）。

★ 推论：★ **目标路由指标不提供独立于知识类型指标的信息量**，
★ 把它作为独立的三项之一会高估证据量。

### 1.4 规则资格是唯一独立于类型与路由的维度

| 项 | 值 |
|---|---|
| 类型与路由同时正确而资格错误 | 0 条 |
| 资格准确率与类型准确率之差 | ★ SIP 0.2593、★ RTSP 0.0、★ SMTP 0.174 |

★ 资格维度捕获了类型维度看不到的差异，★ 是三项中唯一提供独立信息的。

## 二、推论

1. ★ 改进时应以**知识类型**为主攻点，★ 路由随之修复；★ 单独优化路由无意义。
2. ★ 资格维度须**单独评估**，★ 不能因类型对就认为资格也对。

## 三、限制

1. ★ 本分析基于已接触的 57 条。
2. ★ 未修改任何规则，★ 未重算 R14。
