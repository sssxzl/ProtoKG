## 一、已验证事实

### 1.1 为什么必须独立验证

★ 本轮归因使用的 57 条候选**已被逐条人工审核**，★ 且已用于诊断 V2 判据。
★ 按项目既有结论，★ **已接触的样本不得再作为独立泛化测试集**（★ 独立泛化测试集）。
★ 因此任何 V2-next 的修复效果，★ 必须在**未参与本轮归因与调参**的样本上验证。

### 1.2 验证样本的三项要求

| # | 要求 | 说明 |
|---|---|---|
| 1 | ★ **未参与本轮归因与调参** | ★ 新引入的 RFC；★ 不得是已用过的 SIP/RTSP/SMTP/DHCPv4 候选 |
| 2 | ★ **有完整的独立人工 Gold** | ★ 候选级分类真值 + 原子知识级真值；★ 须由与本轮不同的审核者完成 |
| 3 | ★ **规则先于数据冻结** | ★ V2-next 判据、标签映射、投影规则、匹配规则、排除规则须在查看任何预测结果前冻结并登记 SHA256 |

### 1.3 候选来源建议

| 方向 | 理由 | 注意事项 |
|---|---|---|
| ★ FTP（★ 协议文档结构已知、★ 已有历史快照） | ★ 具备命令与状态码两类可判形态 | ★ 须以**新的 RFC 版本**与**新的候选窗口**取样，★ 不复用既有快照 |
| ★ 新版 SIP 或 SMTP 扩展 RFC | ★ 与已用协议同族但非同一文档 | ★ 同族有利于检验「同族内的类型边界」，★ 但须声明这**不是**跨族泛化 |
| ★ 跨族的新协议 | ★ 最强的泛化证据 | ★ 须确保人工 Gold 的类型口径与本轮一致，★ 否则混淆「判据改进」与「口径变更」 |

★ **推荐组合**：★ 一个跨族新协议（★ 主验证）＋ 一个同族新版本（★ 辅助验证）。

### 1.4 验证规模与口径

| 项 | 建议 | 理由 |
|---|---|---|
| ★ 候选级样本量 | ★ 每协议不少于 30 条 | ★ 小于 20 条时单条错误对准确率的影响超过 5 个百分点 |
| ★ 原子知识样本量 | ★ 不少于 10 条 | ★ 覆盖描述性、规范义务、枚举、元数据四类 |
| ★ 审核方式 | ★ A/B 独立 + 第三方仲裁 | ★ 与本轮一致，★ 但审核者须为不同的人 |
| ★ 报告方式 | ★ 分协议；★ 类别分层的准确率与混淆矩阵 | ★ 与 R14 口径一致 |

### 1.5 预注册内容（★ 须在看到预测结果前冻结）

1. ★ V2-next 判据文件与其 SHA256；
2. ★ 六类（或七类）标签集合与路由映射；
3. ★ `strength=unknown` 的契约定义；
4. ★ 投影规则（★ 若沿用 R10-P1，★ 须说明其在本次验证中的性质；
   ★ ★ **建议在新样本上预注册一条事前投影规则**，★ 以便本次验证具备事前预注册性质）；
5. ★ 匹配规则、分母与排除条件；
6. ★ 评估脚本与其 SHA256；
7. ★ 主指标与分层报告口径；
8. ★ 样本量与统计方法（★ 含 RTSP 类小样本的不确定性声明）。

### 1.6 判定标准（★ 须事先定稿）

| 项 | 标准 |
|---|---|
| ★ 主判定 | ★ 知识类型准确率与 R14 首次结果的可比性，★ 须同时给出**绝对数**与**比率** |
| ★ 不做 | ★ **不得**以「V2-next 优于 V2」作为唯一结论，★ 除非给出配对检验或区间估计 |
| ★ 必须披露 | ★ 样本量、协议构成、与本轮 57 条的隔离声明 |
| ★ 禁止 | ★ 看到结果后回头调整判据并沿用「独立评测」表述 |

### 1.7 与本轮 57 条的关系

★ 本轮 57 条降级为**诊断集**：★ 归因证据、方案论证、★ 以及 V2-next 在该集上的
★ **回测表现**（★ 明确标注为已接触数据上的回测，★ 不是独立验证）。
