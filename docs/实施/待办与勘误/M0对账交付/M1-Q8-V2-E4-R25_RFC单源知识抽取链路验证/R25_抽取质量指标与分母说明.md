## 四、指标口径的边界说明

| 指标 | 它**不是**什么 |
|---|---|
| ② 知识类型准确率 | **不是**「分类器准确率」；口径是「kind → aspect 的确定性与单一性」（191/262 的 Norm 映射出单一 aspect） |
| ③ 规范规则资格准确率 | **不是**「规范义务识别率」；分母只含**已有 constraint 的抽取** |
| ⑤ 来源身份保全率 | **不是**「来源正确率」；口径是「能否绑定真实 RFC 文件与 SHA256」 |
| ⑥ Evidence 可追溯率 | **不是**「证据正确率」；口径是「能否定位到确切行」 |
| ⑦ 语义保全率 | **不是**「语义完整率」；口径是「能否映射出至少一个 Fact」（字段级完整率见指标④） |
| ⑩ RFC 文档级覆盖 | **不是**「知识覆盖率」；口径是「产出至少一条 Norm 的 RFC 文档比例」 |

**十项指标中只有②③④⑤⑥⑦⑧⑨⑩可计算；①（端到端召回）无可信人工真值。**
