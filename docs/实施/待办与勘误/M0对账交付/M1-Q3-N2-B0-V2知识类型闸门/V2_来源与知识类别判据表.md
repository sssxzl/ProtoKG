# V2 · 来源与知识类别判据表

> ★ 全部判据**确定性**、★ 只读原文与候选字段、★ **0 次 LLM**
> ★ 每一项都给出可复核的命中信号（★ 见联合 CSV 的「★ 判据信号」列）

## 一、★ 信号层（★ 先算信号，★ 再按优先级组合）

| # | 信号 | 判据 |
|---|---|---|
| S1 | ★ 含 BCP14 强度词 | ★ 正则匹配 **大写** `MUST/SHALL/SHOULD/REQUIRED/RECOMMENDED/MAY` 及其否定形式 |
| S2 | ★ 含否定强度 | ★ `MUST NOT / SHALL NOT / SHOULD NOT / MAY NOT` |
| S3 | ★ 命中文档级对象 | ★ `copyright(s) / notice / trademark(s) / document / translations / copies / derivative works / standards process / Internet Society / all rights reserved / disclaimer(s)` |
| S4 | ★ 命中协议参与方 | ★ `server / client / UAS / proxy / relay / peer / gateway / sender / receiver / requester / responder / endpoint / host / user agent / registrar / DHCP server / SMTP client …` |
| S5 | ★ 命中版权许可表述 | ★ `all rights reserved / copyright notice / this document and translations / may be copied / derivative works / permission to copy / infringement / shall be identified / without restriction` |
| S6 | ★ 落在元数据章节 | ★ 结构位置：★ 向上 60 行内最近的章节标题匹配 `Copyright / Notice / Disclaimer / Trademark / Acknowledgments / Authors' Addresses / Contributors / Intellectual Property` |
| S7 | ★ 行内含 ABNF 形态 | ★ 该行是产生式赋值（`X =` / `X ::=` / `X :=`）**或其续行**（★ 前一行为产生式）★ ※ **单纯的状态码枚举项不算** |
| S8 | ★ 上下文含登记/枚举提示 | ★ 窗口内出现 `status code / error code / option name / registry / registered / IANA / assignment` |
| S9 | ★ 义务动词 | ★ `must / shall / should / may / required to / has to / ought to`（★ 不分大小写） |
| S10 | ★ 陈述式规范句 | ★ **条件从句**（if/when/unless/provided that/in case/whenever）**且** **协议行为动词**（discard/ignore/return/send/…）**且** **协议参与方主体**（S4）**且** **无 S1** |

| 顺序 | 条件 | ★ source_kind / knowledge_kind | ★ rule_eligibility | ★ route |

| 2 | ★ **S7** | `protocol_syntax` | `ineligible` | `structured_channel` |
| 3 | ★ **S8 且 ¬S1** | `protocol_registry_or_enumeration` | `ineligible` | `structured_channel` |
| 4 | ★ **S1 且 S4 且 S9** | `normative_rule_candidate` | `eligible` | `rule_channel` |
| 5 | ★ **S1 且 S3 且 ¬S4** | `non_protocol_metadata` / `mixed_or_uncertain` | `uncertain` | `pending_review` |

| 7 | ★ **S9 且 ¬S1 且 ¬S4**（★ 小写义务动词） | `mixed_or_uncertain` | `uncertain` | `pending_review` |
