## 二、★ 两层标注结构（★ 一个片段可对应 0 / 1 / 多条知识）

### 2.1 ★ 第一层：片段级（★ 每个片段一行）

| 列 | ★ 说明 |
|---|---|
| ★ `★ 是否存在目标知识` | ★ **三态不可互换**：`否`（★ 无目标知识）／`是`（★ 有）／`不确定` |
| ★ `★ 知识类别` | ★ 六类之一（★ 可多选，★ 用分号分隔） |
| ★ `★ 是否需跨句/跨节证据` | ★ 否／跨句／跨节／引用外部章节 |
| ★ `★ 审核意见` | ★ 必填 |
| ★ `★ 不确定原因` | ★ 「不确定」时**必填** |

★ ⇒ ★★ **三态不可互换**：
★ `no_target_knowledge`（★ **看清了没有**）／★ `uncertain`（★ **看不清**）／★ `not_applicable`（★ **不评**）
★ ⇒ ★★ **不得**用 `uncertain` 代替「没有」；★ **不得**用 `not_applicable` 代替「看不清」

### 2.2 ★ 第二层：原子知识级（★ 每条发现的知识一行）

| 列 | ★ 说明 |
|---|---|
| ★ `knowledge_kind` | ★ 六类之一 |
| ★ `evidence_span` | ★ 该知识的行号范围（★ 可多行） |
| ★ `subject` / `action` / `object` | ★ **主体须写出指代解析后的实际承担者**（★ 如「This field」→「CSeq」） |
| ★ `strength` | ★ MUST / SHALL / SHOULD / MAY / REQUIRED / RECOMMENDED / ★ **`unknown`** |
| ★ `polarity` | ★ positive / negative |
| ★ `condition` / `exception` | ★ 原文中的条件/例外；★ 跨句继承须写明继承自哪句；★ 无则 `null` |
| ★ `evidence_support` | ★ supported / partially_supported / contradicted / evidence_insufficient |
| ★ `review_note` | ★ 必填（★ 依据原文哪一行、★ 为什么这样判、★ 哪里不确定） |

★ ★ **新增多条知识时**：★ 复制该 `gold_knowledge_id` 行并把序号改为 `-2`、`-3` …（★ **不得**拆散同一知识的主体/条件/例外）

## 三、★ 三条硬规则

| # | 规则 |
|---|---|
| ① | ★ ★ **原文没有明确给出强度 ⇒ 写 `unknown`，★ 不得写 MUST** |
