## 四、可计算的离线指标（不依赖人工）

这些可以现在就算，作为辅助，不替代 M1–M8：

| 指标 | 定义 | 用途 |
|---|---|---|
| 定位可追溯率 | locator 指向的 RFC 文件存在且为数字行号的比例 | 发现「定位不到文件」的系统性问题 |
| 定位落在标题的比例 | 落点为正则 `^\d+(\.\d+)*\s` 的比例 | 91 条中已测：46/91 |
| 区间歧义率 | 新旧行号区间内同名 token 出现 ≥ 3 次的比例 | 提示人工优先看哪些 |
| 生成来源占比 | `file:rfc:*` / `file:llm@*` 的比例 | 说明有多少条没有真实行号可用 |

## 五、报告要求

1. 每个百分比必须带分母，例如「57/60」而不是「95%」。
2. 分协议报，不只报总平均；DHCPv4 的 36 份扩展文档密度差异很大。
3. 抽样 60 条**不能**当作召回率分母——召回只能来自 M1 的文档级清单。
4. 失败案例清单必须带原文行号与原文片段，便于复核。
5. 不写「质量已达标」，只写「在什么样本、什么口径下得到什么数字」。
