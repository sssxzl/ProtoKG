# R28-C 三条部分匹配语义核对

## 一、结论

3 条 `partial_match` 经回核，**均不构成对 Gold 命题的部分承载**，只与「同一跨度或相邻结构」有关。建议在 R28-C 指标里按 0 条有效部分匹配计，但保留 R28-B 原始标签，不覆盖历史结果。

## 二、逐条核对

### 1. GK-B-DHCPv4-rfc2132.txt-1111-1

| 项 | 内容 |
|---|---|
| 同跨度 Norm | `DHCPv4.option_layout.netbios_over_tcp/ip_datagram_distribution_server` |
| Gold 命题 | （B2 记录中命题文本为空，只有跨度与标识符） |
| 核对 | 该跨度是 NetBIOS over TCP/IP 选项的字段布局；Norm 是选项布局条目，与 Gold 的原子命题不同层 |
| 判定 | 相关结构存在，但**未证明**命题匹配 |

### 2. GK-B-DHCPv4-rfc2132.txt-721-1

| 项 | 内容 |
|---|---|
| 同跨度 Norm | `DHCPv4.option_layout.interface_mtu` |
| Gold 命题 | 「This option specifies whether or not the client may assume that all subnets of t…」（关于子网掩码假设） |
| 核对 | 第 721 行是 Interface MTU 选项；Gold 的句子讲的是 Subnet Mask 选项的语义，两者是不同选项 |
| 判定 | 同一文件不同选项，**命题不同**；部分匹配不成立 |

### 3. GK-B-rtsp-rfc2326.txt-1224-3

| 项 | 内容 |
|---|---|
| 同跨度 Norm | `rtsp.field.status-line` |
| Gold 命题 | 「The client is not required to examine or display the Reason-Phrase.」 |
| 核对 | 第 1224 行属状态行字段区；Gold 讲的是客户端**行为义务**（可不必检查 Reason-Phrase），`status-line` 是**字段定义**，两者不同层 |
| 判定 | 相关结构存在，**未证明**命题匹配 |

## 三、对指标的影响

| 指标 | 计入方式 |
|---|---|
| K3 完整命中 | 0（不变） |
| K4 部分匹配 | 由 3 降为 0（复核后），但保留 R28-B 的 3 作为历史值并注明差异 |
| K5 缺口 | 由 110 升为 113（把 3 条并入缺口），同样保留原值 |

报告写法：`R28-B 口径：0/3/110；R28-C 复核口径：0/0/113`，两者并存，不互相覆盖。

## 四、限制

1. 第 1 条的 Gold 命题文本在 B2 记录里为空，本轮只能依据跨度与标识符判断，无法做句级比对。若需严格结论，须回到 B1 原始文件的「原文支持说明」字段逐字比对——已在覆盖率复核 CSV 的 `Gold命题` 列保留可读片段，但为空的两条仍缺句级依据。
2. 本核对不产生新的人工裁定，只是把「同跨度」与「支持命题」两件事分开。
