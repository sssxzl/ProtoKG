# R28-B4 可比范围召回与分母说明

## 一、口径先说清楚

| 数 | 含义 |
|---|---|
| 130 | 队列 B 冻结清单总行数 = 121 条有效原子知识 + 9 条无目标知识记录 |
| 121 | `status=valid_gold` 的有效知识记录 |
| 113 | 其中属于当前三协议输入范围、可比较的记录（121 − 8 条 SIP） |
| 9 | 无目标记录，用于查误抽，**不进召回分母** |
| 54 | 原始 RFC 片段数，不是 130；片段与知识是两种单位 |

SIP 的 8 条有效记录与 3 条无目标记录标记 `outside_current_scope`，从分母中单列排除，不判为漏抽。

## 二、113 条可比记录的对齐结果

| 标签 | 条数 | 占 113 |
|---|---|---|
| exact_match | 0 | 0% |
| partial_match | 3 | 2.7% |
| missing_extraction | 110 | 97.3% |
| 合计 | 113 | 100% |

按知识类型：

| 类型 | 可比 / 总数 | exact | partial | missing |
|---|---|---|---|---|
| normative_rule_candidate | 32 / 32 | 0 | 0 | 32 |
| protocol_descriptive_semantics | 33 / 40 | 0 | 1 | 32 |
| protocol_syntax | 33 / 33 | 0 | 1 | 32 |
| protocol_registry_or_enumeration | 15 / 16 | 0 | 1 | 14 |
| 合计 | 113 / 121 | 0 | 3 | 110 |

差额 8 条为 SIP，已单列 outside_current_scope。

## 三、110 条 missing 的阶段归因

| 阻断阶段 | 条数 | 判据 |
|---|---|---|
| 抽取后无候选（确定性通道不覆盖散文命题） | 82 | 该文档有 Norm，但 Gold 跨度 ±3 行内没有任何 Norm |
| 文档零产出（解析/分块/通道未产出） | 28 | 该文档在当前构建中 Norm 数为 0 |
| 原文不在输入范围 | 0 | 已单列为 outside_current_scope |
| Parser / Chunk 未覆盖 | 0 | 无法与「无候选」区分，未单独归因 |
| 被类型判别或门禁过滤 | 0 | 无日志证据，不臆断 |
| Norm 构建或去重丢失 | 0 | 无日志证据，不臆断 |
| Canonical 映射异常 | 0 | 映射 262/262 成功，未见异常 |

前两类之外一律写 0，是因为没有证据；不把「可能」写成「已确认」。

## 七、这组数字能说什么、不能说什么

能说：在 B1 这份历史人工金标所覆盖的 113 条可比原子上，当前 RFC-only 确定性链路没有一条完整命中，3 条部分命中，110 条未被抽取。

不能说：

1. 不能说 41 份 RFC 的知识召回率是 0%，B1 只覆盖 14 份文档、54 个片段；
2. 不能说当前模型泛化能力如何，这份 Gold 在历史上已被接触（已揭盲），本轮属历史回归；
3. 不能把 110 条 missing 都说成「系统缺陷」——其中 32 条是规范规则、33 条是语法描述，当前确定性通道本就不承担这类散文命题，真正的缺口归属要等 R29-C 逐文档归因；
4. 不能用这些数字替代 R28-C 的分维度指标。
