### 勘误① RTSP「字符 100% vs 规范义务 51.67%」的口径矛盾

★ **结论：51.67% 是错的，真实值为 100.00%。**

| 口径 | 模拟脚本（旧） | **真实计算（复核）** |
|---|---:|---:|
| rtsp 字符覆盖 | 100.00% | **99.97%** |
| rtsp 行覆盖 | 100.00% | **100.00%** |
| ★ **rtsp 规范义务行覆盖** | 51.67% | ★ **100.00%（120/120）** |

★ **可复算解释**：旧模拟用「**每块固定 58 行**」（`_MAX_BLOCK_CHARS // 60`）**估算**行区间
⇒ ⇒ 行区间被系统性低估 ⇒ ⇒ 规范义务行被误判为未覆盖。
⇒ ⇒ ★ **复核命令**（真实口径）：
```bash
python - <<'PY'
import sys, pathlib, re; sys.path.insert(0,'.')
from core.fused.extraction import prose_semantics as ps
BCP=re.compile(r'\b(MUST NOT|MUST|SHALL|SHOULD|REQUIRED|MAY|OPTIONAL)\b')
p=pathlib.Path('kb/rtsp/spec/rfc2326.txt')
t=p.read_text(encoding='utf-8',errors='replace').replace('\r\n','\n'); L=t.split('\n')
bl=ps._split_blocks(t, 10**6); cov=set()
for s,tx in bl:
    n=tx.count('\n')+1
    for i in range(s, min(len(L), s+n)+1): cov.add(i)
print('规范义务行覆盖', sum(1 for i,l in enumerate(L,1) if i in cov and BCP.search(l)), '/',
      sum(1 for l in L if BCP.search(l)))
PY
```
⇒ ⇒ ★★ **推论修正**：「规范义务集中在文档中后段、按前 N 块会漏掉」**对全文切块不成立**；
