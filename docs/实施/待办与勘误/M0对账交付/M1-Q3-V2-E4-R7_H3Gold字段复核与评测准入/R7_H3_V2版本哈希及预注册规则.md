## 二、预注册规则

### 2.1 评估指标

| 指标 | 定义 | 分母 |
|---|---|---|
| 知识类型准确率 | V2 预测类别与 Gold 类别完全一致的比例 | 22 条候选级 confirmed_valid |
| 目标路由准确率 | V2 预测路由与 Gold 路由完全一致的比例 | 同上 |
| 规则资格准确率 | eligible 与 ineligible 二分判定一致的比例 | 同上 |
| 有效协议知识召回率 | Gold 为正类的候选中被判为正类的比例 | 18 条正类 |
| 非协议元数据识别率 | Gold 为负类的候选中被判为负类的比例 | 4 条负类 |
| 抽取完整性 | 分项统计，★ unresolved 字段单列 | 逐字段可用数 |

### 2.2 匹配规则

1. ★ 预测与 Gold 的知识类别须**完全相同**才算匹配；★ 不做模糊或部分匹配。
2. ★ 目标路由按 Gold 的 `target_route` 字面比对。
3. ★ `mixed_or_uncertain` 与 `pending_review` 不并入任何正确类；★ 计入分母，★ 单列为不确定。
4. ★ 补充知识级 5 条不进入以上任何指标；★ 单独做覆盖分析。

### 2.3 排除条件（★ 在计算前确定）

| 条件 | 处理 |
|---|---|
| `status=excluded`（1 条） | 不进主分母；★ 敏感性分析中按负类计入 |
| `gold_level=supplementary`（5 条） | 不进任何候选分类分母 |
| Gold 字段为 `unavailable` | 对应指标的分母扣除该条，★ 单列 |
| Gold 字段需二次人工确认 | 对应指标分母扣除该条，★ 单列 |

### 2.4 暴露样本标记

★ H3 的 3 个类型归属疑点（H3-02、H3-13、H3-20）★ 已被工程审计接触并经第三方仲裁裁定。
★ 评测报告须标注这 3 条，★ 并给出含与不含这 3 条的对照。

### 2.5 禁止事项

★ 严禁看到 H3 分类指标后调整匹配规则或排除条件，★ 并继续把同一次测试称为独立评估。
★ 预注册文件与哈希在指标计算前归档；★ 指标计算后规则变更须重新走审批。

## 三、限制
