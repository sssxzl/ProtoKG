## 二、★ V1 的判据（★ 命题级 + 作用域级）

### 2.1 `contradicted` 的**充要条件**（★ 三者同时满足）

| # | 条件 | 说明 |
|---|---|---|
| ① | ★ **同一规范命题** | ★ 主体 + 动作 + 对象三者**在同一条证据句上均可定位且对应** |
| ② | ★ **极性相反** | ★ 肯定 vs 否定（★ **强度不一致本身不构成矛盾**：★ MUST vs SHOULD ⇒ 不是矛盾） |
| ③ | ★ **否定作用于候选动作**（★ 作用域） | ★ 否定词必须**紧邻**候选动作词（★ 同子句且词距 ≤ 2）；★ 强度否定（must not 等）作用于动作时同样有效 |

⇒ ⇒ ★ **★ 任一条不满足 ⇒ 一律 `uncertain`**

### 2.2 其余一律 `uncertain` 的情形（★ 用户第 5 条）

| 情形 | 处置 |
|---|---|
| ★ 证据缺失 | uncertain |
| ★ 跨句归属不清 | uncertain |
| ★ 强度范围不一致（★ MUST vs SHOULD） | uncertain（★ **不是** contradicted） |
| ★ 存在多个义务 | uncertain |
| ★ **候选字段自相矛盾**（★ constraint 含否定而 strength 不含） | uncertain（★ **字段不一致，不是反证**） |
| ★ 主体缺失 | uncertain（★ 无法确认同命题） |

### 2.3 ★ 绝不升级为 confirmed

★ **V1 模块没有 confirmed 出口**：★ 只产出 supported / contradicted / uncertain
★ ★ **取消错误反证不会直接产生 confirmed**（★ supported 只表示「可进 LLM 链」）

### 2.4 ★ 可追溯性（★ 用户第 7 条）

★ 每条 contradicted 均记录：**★ 反证句全文** / **★ 反证行号** / **★ 作用域子句** /
★ **★ 命题对应（主体/动作/对象/强度逐项）** / **★ 证据跨度（行号 + 长度）** / **★ 判据原因**

## 四、★ 实现过程中由回归测试暴露的两个真实缺陷（★ 均已修）

| # | 缺陷 | 修法 |
|---|---|---|
| ① | ★ **无差别子串匹配过宽**（★ 「silently ignore」被「silently ignores」的子串误命中） | ★ 改为词形等价 `_morph` |
| ② | ★ **整句级 `_neg_in` 过宽**（★ 条件从句里的 not 被当作对候选动作的否定） | ★ 引入**子句切分 + 紧邻动作**判定（★ 词距 ≤ 2） |
| ③ | ★ **V1 漏了 V0 已有的「合法缺省不阻塞」规则**（★ strength 无值 ⇒ ★ 错误阻止 supported） | ★ 补上：★ strength 合法缺省不阻塞 supported 判定 |
| ④ | ★ **未查「候选 strength 极性 vs 原文同子句强度极性」**（★ 原文 SHOULD NOT 而候选 SHOULD ⇒ ★ 被误判 contradicted） | ★ 新增**强度极性一致性检查** ⇒ 不一致 ⇒ uncertain（★ 字段不一致 ≠ 反证） |

⇒ ⇒ ★ **★ 这两项都是真实缺陷，★ 不是为让样本通过而设的特例**
