### 1.2 ★ 预先冻结的九项指标

| # | 指标 | 口径 |
|---|---|---|
| 1 | ★ knowledge_kind 准确率与混淆矩阵 | ★ 行 = Gold、★ 列 = 预测；★ 完全相同才算匹配 |
| 2 | ★ eligibility 准确率 | ★ eligible 与 ineligible 二分；★ uncertain 单列 |
| 3 | ★ target_route 准确率 | ★ 按 Gold 的 target_route 字面比对 |
| 4 | ★ 三维度同时正确的候选比例 | ★ 三项同时匹配 |
| 5 | ★ V2 与 V2-next 的逐候选配对变化 | ★ 逐 candidate_id 对齐 |
| 6 | ★ 修复数量、由对变错数量与净变化 | ★ 修复 = V2 错而 V2-next 对；★ 由对变错 = V2 对而 V2-next 错 |

| 8 | ★ 完整样本分母、无预测样本与错误归因 | ★ 无预测样本单列，★ 不计入分母 |
| 9 | ★ 统计不确定性与样本量限制 | ★ 小样本须声明置信区间宽 |

### 1.3 ★★ 两条必须披露的相关性

| 项 | 说明 |
|---|---|
