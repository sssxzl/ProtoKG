# R20 独立人工 Gold 盲审方案

> ★ **方案，★ 待审批** ｜★ 人工 Gold 冻结后才允许正式评分

---

## 一、已验证事实

### 1.1 审核者安排

| 角色 | 人数 | 职责 | 独立性要求 |
|---|---:|---|---|
| ★ 审核者 A | 1 | ★ 独立识别片段中的原子知识并标注 | ★ **不得**是 D、C、F；★ 不得参与 V2 或 V2-next 的任何调试 |
| ★ 审核者 B | 1 | ★ 同上，★ 与 A 独立 | ★ 同上 |
| ★ 第三方仲裁 | 1 | ★ 裁定 A/B 分歧 | ★ 同上 |

### 1.2 ★ 盲审的硬性要求

| # | 要求 | 机制 |
|---|---|---|
| 1 | ★ 审核者**不得**查看机器预测 | ★ 发给审核者的材料只含 RFC 原文、证据跨度与待填列 |
| 2 | ★ 审核者**不得**查看 V2-next 的错误分析结果 | ★ R15～R20 的归因与错误分析材料不进审核包 |
| 3 | ★ 审核者**不得**与既有审核者重合 | ★ D、C、F 已参与既有环节，★ 须回避 |
| 4 | ★ 片段可含零条、一条或多条 | ★ 表结构须支持一片段多行 |

### 1.3 ★ 两类分母必须分开

| 评价类型 | 分母 | 口径 |
|---|---|---|
| ★ 候选级分类评价 | ★ 候选级 Gold 条数 | ★ knowledge_kind、★ eligibility、★ target_route |
| ★ 原子知识召回评价 | ★ 原子级 Gold 条数 | ★ 抽取出的原子知识与人工原子知识的匹配 |

★ ★ **两者不得混用**，★ 也**不得**把候选级准确率当作端到端知识召回率。

### 1.4 人工 Gold 的标注项

| 项 | 取值 |
|---|---|
| ★ knowledge_kind | ★ 六类枚举 |
| ★ rule_eligibility | ★ eligible / ineligible / uncertain / not_applicable |
| ★ target_route | ★ 五条路由 |
| ★ 主体、动作、对象 | ★ 文本；★ 非行为知识可记 not_applicable |
| ★ 规范强度、极性 | ★ 枚举或 not_applicable |
| ★ 条件、例外 | ★ 文本或空 |
| ★ 证据跨度 | ★ 行号区间 |

### 1.5 ★ 流程与冻结

1. ★ 材料准备（★ 只含原文与跨度）；
2. ★ A 与 B 独立完成；
3. ★ 第三方仲裁分歧；
4. ★ **人工 Gold 冻结并登记 SHA256**；
5. ★ ★ **冻结之后**才允许运行正式评分。

★ ★ 若在步骤 4 之后因任何原因调整了 V2-next，★ **本批样本即降级为开发集**，
★ ★ 不得再称为独立验证。

## 二、限制

1. ★ 审核者尚未确定，★ 须先排除 D、C、F。
2. ★ 本轮不产出任何人工 Gold。

## 三、下一步

★ 审批本方案 → 确定审核者 → 准备盲审材料 → 独立标注 → 仲裁 → 冻结 Gold。
