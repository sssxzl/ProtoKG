### 1.6 ★ 结论

★ **RFC 3659 与 RFC 959 的独立测试身份成立。**

★ ★ 但须附带一条**已披露的关联**：★ RFC 3659 是「Extensions to FTP」，★ 它 Updates RFC 959，
★ 而 RFC 959 又被 RFC 2228/2640/2773/5797/7151 更新。★ 因此 3659 的内容**大量依赖** 959 的基础规范。
★ ★ 这正是本轮把 959 列为「背景参考文档」的原因（★ 见预注册），★ 也意味着：
★ ★ **若只用 3659 做主评估分母，★ 涉及命令格式等基础规范的义务将落在 959 里。**
