## 二、边界

- 散文型（3207）：表现好；
- 表格/字段型（2131）：语义条目可，结构条目漏；
- 语法型（9112）：结构条目大量漏。

## 四、决策建议

不建议继续跑 9293 来"多看一份"。已复现的规律足够明确：**缺的是结构化知识通道，不是 Prompt**。

建议下一步二选一（都需批准）：

A. 恢复/接入确定性 ABNF 与表格通道，与 v6 并行；
B. 接受当前边界，把 T0-A 限定在"散文型 RFC"，结构化知识另立项。

## 五、明确不做

不改 Prompt v6；不把 2131/9112 的低召回说成"样本不足"；不合并两文档的召回率成一个数。
