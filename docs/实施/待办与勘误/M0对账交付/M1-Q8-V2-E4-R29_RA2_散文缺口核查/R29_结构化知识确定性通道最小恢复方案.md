# 结构化知识确定性通道最小恢复方案

## 一、实现

`scripts/structural_extract.py`（影子，未接入正式链路）：

| 函数 | 识别对象 | 输出 |
|---|---|---|
| `abnf_rules` | `name = expr` 及续行 | 规则名、表达式、起止行、连续 quote |
| `mbz_bits` | `MBZ` / `MUST be set to zero` / `reserved … zero` | 行号、原句 |
| `table_rows` | `字段名  长度  说明` 三列行 | 字段名、长度、说明、行号 |

## 二、设计约束

- 只识别形态，不推断原文没有的 MUST；
- 每条都带连续原文 quote（表格/位域为单行，ABNF 为规则块）；
- 不做跨段拼接，多段来源另行记录；
- 输出为侧车 JSON，尚未映射为 Fact。
