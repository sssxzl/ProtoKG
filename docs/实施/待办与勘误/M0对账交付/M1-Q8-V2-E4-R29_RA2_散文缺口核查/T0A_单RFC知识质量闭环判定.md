| 指标 | 值 |
|---|---|
| Raw 保留率 | 28/28 |

## 二、这个 28/28 的构成

| 来源 | 条数 |
|---|---|
| 模型原始引用直接支持 | 20 |
| 唯一实体重锚（168、226） | 2 |

| 归一化依赖 | 2（210 空白、285 小写 must） |

（口径按条目归属，不重复计数：28 = 20 原始 + 2 重锚 + 6 对齐/改配）

## 三、登记

```
T0_A_v6_semantic_support_28_28_verified
```

## 四、必须附带的限定

1. 5 条是**程序 + 人工改配引用**，不是模型自己给的；
2. 210、285 依赖空白/大小写归一化，已在文档记录；
3. 官方 Hub 不承载完整 quote，验证状态在侧车；
4. 本结果只覆盖 RFC 3207 一份文档，**不代表跨 RFC 泛化**；
5. 341 的成功来自 v6 的承接句规则，该规则在别的 RFC 上是否同样有效未验证。

## 六、建议

T0-A 单 RFC 可关闭，标记 `T0_A_single_rfc_closed`。跨 RFC 前先做一次不同协议的抽样，避免把 v6 规则当成通用解。
