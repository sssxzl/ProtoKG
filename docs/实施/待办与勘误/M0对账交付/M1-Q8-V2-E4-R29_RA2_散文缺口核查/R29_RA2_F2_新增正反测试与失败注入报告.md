## 三、失败注入方式

| 方式 | 用法 |
|---|---|
| 指定文档抛错 | `Stub(fail_docs={"b.txt"})` |
| 第 N 次调用后抛错 | `Stub(raise_after=0)` |
| 空结果 | `Stub(empty_docs={"a.txt"})`，返回 `{"items": []}` |
| 单块批次 | `PROSE_BATCH_BLOCKS=1`，让 A/B 分属不同批次 |

## 四、被测试逼出的两个实现缺陷

1. 局部变量 `_doc_meta` 与函数 `_doc_meta` 同名 ⇒ `UnboundLocalError`，改名 `_dmeta`；
2. 空来源仍写缓存 ⇒ 写进去也读不出来，改为跳过。
