## 三、过滤与误报

- 2131 附录 `MTU`、`RD` 两条误报：**未进入**本轮闭环（只取 siaddr）；
- 9112 同名规则重述：本轮只取 `request-line` 一条，未发生合并；
- 结构化候选与 v6 命题的重叠检查：D4/H2 在 v6 中均无对应条目，无重复。

## 四、集合口径

```
prose_only            2131:74 / 9112:53（未变）
structural_only       形态侧车（ABNF 81 + 位域 5 + 表格 13）
```

不能把 2 说成"恢复了 2 条知识"——它们是语法形态，不是完整知识条目。
