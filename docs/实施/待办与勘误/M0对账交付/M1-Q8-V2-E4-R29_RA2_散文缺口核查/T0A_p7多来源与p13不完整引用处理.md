## 一、p7：STARTTLS 命令格式与无参数

命题含两点：命令为 `STARTTLS`、且不带参数。

原文分散在两处：

- 84 行：`(3) the STARTTLS keyword has no parameters;`
- 105–106 行附近的 501 码说明：`501 Syntax error (no parameters allowed)`

模型在第二阶段返回 `multi_source`，未给 quote。

处理：按规则不拼造单段引用，标记 `multi_source_pending`，侧车保留两条候选证据的定位结果，等待人工或多次证据关联机制。

**未做**：不改 Evidence Schema，不把两段拼成一条假 quote。现有 Evidence 契约（一个 Claim 一条 Evidence）确实无法表达「多段共同支持」，这条限制如实记录。
