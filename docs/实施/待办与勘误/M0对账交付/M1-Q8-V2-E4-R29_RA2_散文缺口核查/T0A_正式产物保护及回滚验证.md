## 二、文件级保护（不只是数量）

- 记录 `derived/per_source` 与 `derived/hub` 下每个文件的 SHA256，运行后逐一比对，无变化；
- 未调用 `_clean_per_source` / `_purge_hub_for_batch`；
- 所有写操作发生在 `mkdtemp` 目录内。

## 三、失败注入

在隔离目录内构造「内部 item 串文档」的坏缓存后再执行加载，进程按预期拒收并继续；正式目录未产生任何写入。

## 四、回滚

| 对象 | 方式 |
|---|---|
| 缓存污染修正 | `git apply -R T0A_缓存污染拒收最小修正.patch` |
| 此前四段补丁 | 依次 `git apply -R` |
| 隔离产物 | 删除对应临时目录即可 |

## 五、结论

正式产物与历史缓存未变；回滚路径齐全。
