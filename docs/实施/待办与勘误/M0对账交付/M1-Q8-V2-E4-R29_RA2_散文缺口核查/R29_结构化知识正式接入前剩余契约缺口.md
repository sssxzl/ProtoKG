# 结构化知识正式接入前的剩余契约缺口

| # | 缺口 | 影响 | 是否阻塞 D4 |
|---|---|---|---|
| 1 | 无语法/产生式 aspect | ABNF 借用 `syntax`，语义上不精确 | 否 |
| 2 | subject 只有 header/actor/protocol 等 | 请求行、字段表被标成 header | 否（可用，但不准） |
| 3 | 位域需「图例 + 规范句」两段证据 | Claim↔Evidence 一对一承载不了 | 是（D3 类） |
| 4 | 表格跨行/多单元关系 | 单行表可用，多行表无法表达 | 否（当前样例是单行） |
| 5 | 人工释义无出处 | definition 里的中文释义非 RFC 原文 | 否（标注即可） |

## 结论

D4 与 H2 都能在现有契约内闭环，代价是类型借位与释义标注。D3（位域）仍被第 3 条卡住，需要多段证据机制。
