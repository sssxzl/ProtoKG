## 三、剩余限制（不掩盖）

1. **真实输出等价性不可验证**：没有可合法消费的完整散文缓存，也没有真实 LLM 调用。所有结论来自合成桩。
2. **并发未覆盖**：单进程假设，多进程同时写同一文档缓存可能竞争。
3. **空结果语义**：`success_empty` 表示「跑完没抽到」，但当前无可信样本证明该判定在真实模型下准确。
4. **键不覆盖块切分算法版本**：`block_sig` 覆盖结果边界，但若切分算法改变而边界恰好一致，键不会变。这是残留风险，需在 schema 版本升级时人工处置。
