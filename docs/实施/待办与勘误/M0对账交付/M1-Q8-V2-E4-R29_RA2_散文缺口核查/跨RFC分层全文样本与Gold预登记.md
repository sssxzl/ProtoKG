# 跨 RFC 分层全文样本与 Gold 预登记（运行前冻结）

## 一、样本可得性核查（先于任何调用）

| RFC | 协议/层 | 本地是否存在 | 状态 |
|---|---|---|---|
| RFC 2131 | DHCP / 应用层（UDP 承载） | 是（`kb/DHCPv4/spec/rfc2131.txt`，113 738 字符，2 524 行） | 可执行 |
| RFC 9112 | HTTP/1.1 / 应用层 | **否**（`kb/` 下无 http 目录） | **阻断** |
| RFC 9293 | TCP / 传输层 | **否**（`kb/` 下无 tcp 目录） | **阻断** |

说明：本轮审批指定了 9112 与 9293，但知识库现有协议只有 DHCPv4、rtsp、sip、smtp。两份文本不在本地，也未登记 SHA256。

按「不得根据模型表现临时替换 RFC」与「新样本需冻结原文并登记哈希」，我不做以下替代：

- 不下载后临时当样本（原文来源与哈希未经登记）；
- 不拿 rtsp/sip/smtp 顶替（其中 smtp 已 exposed，rtsp/sip 未经批准）。

因此本轮只能执行 RFC 2131 全文；9112、9293 登记为输入阻断，等批准入库后再跑。

## 二、RFC 2131 Gold 预登记（运行前固定，共 6 条）

| 编号 | 行 | 类型 | 命题 | 强度 |
|---|---|---|---|---|
| D1 | 498–501 | 普通规范 | client identifier 在子网内唯一且后续消息一致 | MUST ×2 |
| D2 | 1711–1712 | 承接型 | 服务器不应复用已提供的地址（Therefore 承接） | SHOULD NOT |
| D3 | 587 | 普通规范 | flags 保留位必须置 0 | MUST |
| D4 | 508–510 | 定义 | siaddr 表示下一步引导服务器 | 无 |
| D5 | 1698 | 条件型 | ciaddr 在 DHCPREQUEST 中必须为 0（特定状态） | MUST |
| D6 | 1718 | 例外型 | DHCPDISCOVER 中 server identifier 不得填写 | MUST NOT |

评估口径：Raw 是否产出该命题；主体/动作/对象/强度/条件是否正确；锚点是否可回溯。召回率分母 = 6，仅代表预登记样本，**不代表全文总召回**。

## 三、分层抽样（用于非 Gold 知识）

按章节分层（1 引言 / 3 字段格式 / 4 服务器行为 / 5 客户端行为 / 6 中继 / 7 安全），每层随机抽 3 条，共 18 条，审查分母 18。
