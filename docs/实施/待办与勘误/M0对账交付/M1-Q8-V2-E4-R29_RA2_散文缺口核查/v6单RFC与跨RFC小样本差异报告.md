# v6 单 RFC 与跨 RFC 小样本差异

| 维度 | RFC 3207（SMTP） | RFC 2131（DHCP，2 块） |
|---|---|---|
| 块数 | 6 | 2 |
| 请求 | 2 + 1（二阶段） | 1 + 1 |
| Norm | 28 | 12 |
| 承接型义务 | 341 命中 | 1712 命中 |
| 普通规范 | 覆盖 | 覆盖（MUST/MUST NOT 各自成条） |
| Evidence 定位 | 28/28 | 12/12 |
| 语义审查 | 28/28（单人） | 4/12 抽查，其余 pending |

## 一、能说明什么

v6 的两类能力（承接句、普通规范）在这份 DHCP 小样本上没有明显失效；Evidence 定位器对非 SMTP 文本同样工作。

## 二、不能说明什么

- 不能说明 v6 跨 RFC 稳定泛化：只 2 块、单协议、无全文；
- 不能说明召回率：样本小，没有分母；
- 不能说明其他协议无需评估。

## 三、结论

未发现明显泛化失败迹象。若要结论，需要按协议分层抽样，并对全文跑一次。
