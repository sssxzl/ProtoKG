## 二、保留的安全约束

1. 每轮执行前申报批次数与请求数（本轮 2 批 / 2 次）；
2. 超时、截断、非法 JSON、下游失败 ⇒ 立即停止本轮；
3. 每次调用记录 usage、费用、finish_reason；
4. 全部产物写入独立隔离目录；
5. 不写正式 derived / Hub / Seed / GraphRAG，不推 main。
