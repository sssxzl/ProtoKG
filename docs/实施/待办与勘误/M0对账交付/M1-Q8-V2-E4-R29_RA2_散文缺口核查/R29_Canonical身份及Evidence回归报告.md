# Canonical 身份与 Evidence 回归

## 一、身份

结构通道**未映射为 Fact**，因此本轮没有产生任何新 NormID / FactID / ClaimID，也不存在碰撞或既有身份变动。

RFC 3207 的 28 条证据集合未触碰。

## 二、Evidence 可承载性

| 结构 | quote 形态 | 现有契约能否承载 |
|---|---|---|
| ABNF 规则块 | 连续多行 | 可（单段） |
| 表格单行 | 单行 | 可 |
| 位域图例 + 说明 | 图例与说明分离 | **不可**（需多段） |

位域类知识需要「图例 + 规范句」两段证据，现有 Claim→Evidence 一对一结构无法表达，按规则标 pending，不升级。

## 三、结论

本轮零新增知识进入任何集合；回归无回退。
