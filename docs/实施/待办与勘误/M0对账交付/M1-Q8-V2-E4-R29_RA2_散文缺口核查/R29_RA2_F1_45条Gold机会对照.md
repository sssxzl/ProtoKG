# R29 RA-2 F1 45 条 Gold 抽取机会对照

## 一、口径

只判断「新判据下是否获得抽取机会」，不判断「是否真的抽到」。因此本表全部为 `opportunity_granted`，不代表知识恢复。

## 二、按文档分布

| 文档 | 条数 | 原缺失原因 | 新判据下 |
|---|---|---|---|
| smtp rfc5321 | 20 | 通道关闭 | 进入 P1 |
| DHCPv4 rfc1542 | 9 | 触发条件（有确定性产出） | 进入 P1 |
| rtsp rfc2326 | 5 | 通道关闭 | 进入 P1 |
| DHCPv4 rfc2131 | 5 | 触发条件 | 进入 P1 |
| smtp rfc5322 | 3 | 通道关闭 | 进入 P1 |
| smtp rfc3207 | 2 | 通道关闭 | 进入 P1 |
| smtp rfc4954 | 1 | 通道关闭 | 进入 P1 |
| 合计 | 45 | — | 45 获得机会 |

## 三、与 RA-1 的 32 条 syntax、19 条散文结构规则的关系

按 Gold ID 去重后，45 条与 RA-1 的 32 条**无重叠**（前者是散文通道类，后者是确定性 syntax）。19 条散文结构规则若与 45 条有交集，按 Gold ID 去重后计入一次，本表已按文档汇总，不重复计数。

## 四、限制

1. 「获得机会」不等于「能抽到」。抽到与否需要真实模型运行。
2. 20 条集中在 rfc5321，单文档占比高，结论会被这一份文档主导，报告必须分文档。
3. P2 的 26 份零产出文档没有 Gold，无法评估机会，只能盲跑。
