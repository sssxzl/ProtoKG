## 二、句界恢复算法及限制说明

### 2.1 算法（★ 确定性）

```
① 锚点定位（★ 有限窗口）
   ├ 在锚点 ±10 行内找**含 entity 的行**（★ 优先向上，其次向下）
   ├ 找到 ⇒ ★ **锁定**锚点（★ 即使该行被判为「标题」也保留 ⇒ 它就是内容行）
   └ 未找到 ⇒ 锚点行若非散文行 ⇒ ★ 归一化到最近的散文行（★ 优先向上）⇒ ★ 记原因
② 逻辑行（★ 连续散文行）
   └ 空行 / 章节标题 / 图注表注 / ABNF / 表格 / 页脚 ⇒ ★ 构成边界（★ 不并入）
③ 句子切分（★ 逻辑行内）
   └ 句末标点 + 空白/行尾；★ 排除小数点、章节引用、缩写
④ 句选择
   ├ 锚点偏移落在某句内 ⇒ 取该句
   ├ 落在**句间缝隙** ⇒ ★ 优先取「含 entity 的句」，其次「锚点行所在句」，再次保守取首句
   ├ ★ **锚点行内含句末** ⇒ ⇒ 取**下一句**（★ 例：sip@10466）
   └ ★ 取到不含 entity 的句 ⇒ ★ 记 degraded + 原因（★ 不外扩、不猜测）
⑤ 辅助证据
   └ 前一句（条件/指代/例外/引用）⇒ ★ **单独标记**（`aux_evidence`）⇒ ★ **不并入主要 quote**
⑥ 边界与限制
   ├ 最大证据长度 1200 字符 / 12 行 ⇒ 超出 ⇒ ★ 保守降级并记原因
   ├ 跨 chunk ⇒ ★ **允许跨块取证**（同一版本 RFC 真实原文）⇒ ★ **独立记录** `cross_chunk`
   └ 锚点越界 / 句界不可确定 ⇒ ★ 保守处理 + 记原因
```

### 2.2 明确的限制

| # | 限制 | 说明 |
|---|---|---|
| 1 | ★ **不做等价语义推断** | quote 只取**原文**，★ 允许 LLM 补写缺失原文**、★ 不为寻找匹配对象扫描任意远处文本** |
| 2 | ★ **entity 定位窗口 ±10 行** | ★ 有限窗口（与 `entity_in_span` 的 ±3 同阶） |
| 3 | ★ **辅助证据不并入** | 前一句只作**单独标记**的辅助证据 ⇒ ★ **不得据此认定跨句义务成立** |
| 4 | ★ **验证器只看主要 quote** | ⇒ ★ 主体为指代（"This field"）时 ⇒ ★ 主体归属仍需跨句 ⇒ ★ **可能产生「证据完整但主体歧义」的 confirmed**（★ §五 已标出） |
| 5 | ★ **不改动语义验证** | 若窗口修复后仍有误拒 ⇒ ★ **独立记录，不在本轮改验证器** |
