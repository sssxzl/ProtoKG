## 三、归属核验算法（A2 五项检查的落点）

| A2 要求 | 实现 |
|---|---|
| ① 是否存在明确先行词 | ★ 在**同一段落**内按 `the/a/an/each/every/any <X> <名词类>` 模式扫描；★ **不跨段**（★ 跨段 ⇒ 未解析） |
| ② 先行词是否与候选实体类型一致 | ★ 只取**与指代名词类相同**的先行词 |
| ③ 是否存在多个可能先行词 | ★ 计数；★ 同类型多个 ⇒ 歧义 |
| ④ 归属关系是否受原文明确支持 | ★ 先行词修饰名须与候选 `entity` **一致**（双向包含）；★ 且**该类型下唯一** |
| ⑤ 前后规范句是否属不同义务 | ★ **只取一条句**为证据；★ 前一句作**辅助证据**（★ 不并入）⇒ ⇒ 主体不串到下一句 |
| ★ **不得仅按「距离最近」推断** | ★ **显式实现**：即使有一个先行词与实体一致，★ **只要同类型另有先行词 ⇒ 判歧义**（★ 见 §四 反例） |

⇒ ⇒ **四类输出状态**

| 状态 | 含义 | 后续处理 |
|---|---|---|
| `explicit_subject` | 主体在主要证据中明确出现 | ★ 不干预 |
| `coreference_resolved` | 通过上下文**唯一**确认先行词 | ★ 允许 confirmed |
| `coreference_ambiguous` | 多个可能归属 | ★ **不得自动确认** ⇒ confirmed → pending |
| `coreference_unresolved` | 缺乏足够证据 | ★ **不得自动确认** ⇒ confirmed → pending |

★ **保留原始候选主体与证据，★ 不重写 canonical 身份**（★ 只改 `final_state` 并留痕）
