## 二、★ 方案：隔离式离线抽取（★ 与生产完全隔离）

### 2.1 隔离要求（★ 全部为硬约束）

| # | 要求 | ★ 实现 |
|---|---|---|
| ① | ★ **与生产运行隔离** | ★ 独立脚本、★ 独立输出目录（★ `derived/experiments/` 或 `guard/_out/`）、★ **不写正式 Fact 空间** |
| ② | ★ **使用事先固定的模型、Prompt 和版本** | ★ 记录 `model` / `prompt_hash` / `code_commit`；★ ★ **与 V0/V1/V2 判据无关**（★ 抽取器不感知 V2） |
| ③ | ★ **不根据 V2 预测结果挑选测试样本** | ★ 抽样在抽取**之前**按原文结构规则确定（★ 章节类型 + 协议配额 + 文档上限） |
| ④ | ★ **记录所有失败和未生成候选的情况** | ★ 逐 chunk 记录「抽取成功 / 失败 / 未产出候选」及原因 |
| ⑤ | ★ **来源覆盖与抽样概率可追溯** | ★ 逐条记录抽样框、层配额、抽中数、概率 |
| ⑥ | ★ **执行前取得单独授权** | ★ ★ **本轮未授权 ⇒ 不执行** |
