## 一、已验证事实

### 1.1 勘误项一：字段取值解析缺陷（★ 2 条）

★ 原因：★ v1 的取值解析只覆盖「Gold 取 X」「判 X」两种句式，★ 未覆盖 C 实际使用的
★ 「Gold 取 A：具体内容」与「仲裁：主体=X」两种写法。

| Gold ID | 字段 | v1 值（★ 错误） | v2 值（★ 依据 C 裁定） |
|---|---|---|---|
| GK-H3-03-1 | 规范义务主体 | the FORCERENEW message（第217行被动句，句中未指明实施认证的实体） | DHCP 服务器（发送方，须加认证） |
| GK-H3-05-1 | 规范义务对象 | A | once among all instances of this option |

★ 两处均为解析缺陷，★ **C 的裁定本身无缺陷**。

### 1.2 勘误项二：polarity 未标 unavailable（★ 23 条）

★ 候选级 23 条的 polarity 全部改为 `unavailable`。★ 反馈表未提供该列，★ 逐字段差异表也无该字段的独立裁定行。
★ 按要求不做自动推断。★ 补充知识级 5 条的 polarity 有 C 裁定（positive 4、negative 1），★ 保留。

### 1.3 勘误项三：extract_completeness 存储格式（★ 23 条）

★ v1 存的是 C 的仲裁原文（★ 非枚举值），★ 无法用于统计。★ v2 改为枚举值，★ 并另存仲裁原文与依据。
