## 十二、残余风险（**明确未关闭**）

| # | 风险 | 状态 |
|---|---|---|
| 1 | **全链路原子发布 / 失败回滚** | ★ **范围外且未关闭**：抽取层只能保证「闸不通过 ⇒ 不写盘」⇒ ⇒ **不能据此宣称生产发布安全** |
| 2 | **文本→XML/AST 统一文档模型** | 阶段外：当前输入为 TXT |
| 3 | **完整 ABNF 语义**（增量 / 递归 / 重复 / 大小写） | 阶段外 ⇒ 建议：抽到 ABNF 时标注「**语法完整性未知**」（元数据） |
| 4 | **跨 RFC 引用与 IANA 注册表快照** | ★ 阶段外（**确需外部数据源与网络**）⇒ ★ 与「同 RFC 跨节引用」**已分开**（后者本轮支持定位） |
| 5 | **状态机边的守卫条件 / 动作 / 角色** | 阶段外：`target_state` 现为「目标状态名」文本 ⇒ 扩展会改 value 结构 ⇒ **需单独决策** |
| 6 | **完整 P/R/F1 语义评测** | 另立项（评测层）⇒ ★ 本轮以**最小语义回归集**替代 |
| 7 | **规范时效性** | ★ 本轮只做「文档自述状态」登记 ⇒ **不声称**「当前生效」⇒ ⇒ 时效性仍**未关闭** |
| 8 | ★ **规则与普通定义同 aspect 的结构性风险** | 本轮以「身份唯一性 + 混装隔离 + 消费端兼容检查」三道闸覆盖 ⇒ ⇒ 若核查发现结构性冲突 ⇒ ⇒ 走 §2.3 降级路径 |

### ★ 本轮（2026-11-13 晚）新增的未关闭项

| # | 项 | 实测数据 | 建议方向 |
|---|---|---|---|
| 1 | ★ **主体解析率偏低** | 132/471（**28%**）主体 resolved；其余 339 条因主体不可核对 ⇒ 归待审 | ① prompt 补充「主体可在上文/被动语态中找」的提示；② 允许主体落在**上一行**（与证据跨行窗口对齐） |
| 2 | ★ **确定性语义支持前置对「抽象化动作词」过严** | L2 真实调用 90 次 ⇒ **rejected 68 / pending 17 / confirmed 5**；68 条被拒**主因**是「原文未出现动作『list』」这类 | ① 要求 prompt 强制使用**原文动词**；② 或让前置检查支持**词干/同义**匹配（当前仅去尾字母 `e`） |
| 3 | ★ **L2 未用独立模型** | 当前 L2 与抽取**同模型**（deepseek-flash）⇒ 存在**相关性错误**风险 | L2 改用**不同模型**（或不同供应商）⇒ 降低相关性错误 |
| 4 | ★ **通道 J 灰度阈值仍待定** | 影子模式产出 471 条（confirmed 5）⇒ 可作阈值标定的样本 | 以**人工复核通过率**定阈值（★ 不是以产出量定） |
| 5 | ★ **独立抽样漏检检查未跑真实抽样** | 机制已具备（`sampling_miss_check`） | 从**未触发 LLM 的段落**抽样 ⇒ 检查漏抽 |
| 6 | ★ **规范时效性**（跨文档 Updates/Obsoletes 的实际影响） | 只登记**文档自述状态** | 需外部依赖（各 RFC 之间的关系）⇒ 本轮未做 |
