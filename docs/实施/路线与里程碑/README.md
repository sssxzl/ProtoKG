## 五、★ 使用约定

| 想做的事 | 该看/该改哪里 |
|---|---|
| 改 **RFC 源抽取** | 先读 `RFC源/方案与路线/` ⇒ 改 ⇒ 写 `RFC源/实施报告/` |
| 改 **中枢** | 先读 `中枢/中枢流水线状态.md`（冻结契约）⇒ 改 ⇒ 写 `中枢/` |
| 记 **未完成的事** | ⇒ `docs/实施/待办与勘误/`（★ 本目录**不记**未完成项） |
| 归档**已完成的事** | ⇒ 本目录（完成物）＋ 待办目录里**删掉**对应条目（⇒ 避免两处状态不一致） |
| 引用本目录文件 | 用**完整相对路径**（如 `docs/实施/路线与里程碑/RFC源/实施报告/RFC源调通报告.md`） |

⇒ ⇒ ★ **状态一致性规则**：一个条目在「待办目录」出现 ⇒ **还没做**；
只在「本目录」出现 ⇒ **已做完**（★ 两边都出现 ⇒ **状态不一致，需清理**）
