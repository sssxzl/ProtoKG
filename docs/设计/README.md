| 协议知识中枢架构调整方案 ↔ 架构调整方案评审 | 0 | **不合并**（方案 + 评审存档，评审结论已落地） |

| 种子生成/规则集设计 ↔ source源规则集设计 | 0 | **不合并**（种子层 ↔ 源层，层级不同） |
| 五源融合框架 ↔ 五源融合传导设计 | 0 | **不合并**（框架 ↔ 传导落地） |
