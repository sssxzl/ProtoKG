## 一、已验证事实

### 1.1 适配物

| 项 | 值 |

### 1.2 ★ 评估器支持的字段与输出

| 方向 | 支持项 |
|---|---|
| ★ 输入 | ★ candidate_id（唯一身份）、★ source_document（固定 RFC 来源）、★ source_span、★ knowledge_kind、★ rule_eligibility、★ target_route |
| ★ 输出 | ★ 三个指标各自的正确数与准确率；★ 混淆矩阵（★ 行=Gold、★ 列=预测）；★ 逐候选错误明细；★ 跨指标错误记录数；★ 配对异常清单；★ 未配对项显式列出 |

### 1.3 ★ 确定性映射的披露（★ 按审批要求）

★ 评估器的输出中固定包含：

```
note_type_route_mapping:
  类型与目标路由存在确定性映射，路由准确率不构成独立于类型准确率的质量证据
```

★ 并附两个计数：★ 「预测路由违反类型映射的条数」与「Gold 路由违反类型映射的条数」。

★ ★ **⇒ 路由准确率不会被表述为两次独立验证。**

### 1.4 ★ 配对比较（★ V2 与 V2-next）

★ `paired_compare()` 输出：★ 配对候选数、★ 修复数、★ 由对变错数、★ 净变化、
★ 修复候选清单、★ 由对变错候选清单。

## 二、★ 14 类异常的覆盖与规则

| # | 异常 | 规则 | 测试 |
|---|---|---|---|
| 1 | ★ 空候选集合 | ★ **fail-closed**（★ EvalError） | T-02 |
| 2 | ★ 一条候选 | ★ 分母 1，★ 正常计算 | T-03 |
| 3 | ★ 一个片段多条候选 | ★ 按 candidate_id 分列，★ **不折叠** | T-04 |
| 4 | ★ 重复 candidate_id | ★ **fail-closed** | T-05 |
| 5 | ★ 缺少机器预测 | ★ **fail-closed**（★ strict 模式） | T-06 |
| 6 | ★ 多余机器预测 | ★ **fail-closed**（★ strict 模式） | T-07 |
| 7 | ★ 未知或非法知识类型 | ★ **fail-closed**（★ 枚举校验） | T-08 |
| 8 | ★ not_applicable 与 unknown 的差异 | ★ **两者是不同枚举值**，★ 不等值；★ 资格判错而类型判对 | T-09 |
| 9 | ★ 机器候选与 Gold 无法配对 | ★ **fail-closed** | T-10 |
| 10 | ★ RFC 来源身份不一致 | ★ **fail-closed** | T-11 |
| 11 | ★ V2/V2-next 候选集合不同 | ★ 未配对项被**显式报出**（★ 非 strict 模式） | T-12 |
| 12 | ★ 静默跳过 | ★ 非 strict 模式仍列出「未配对的机器预测/ Gold」 | T-13 |
| 13 | ★ 分母为零 | ★ 准确率为 **None**（★ 不报 0.0） | T-14 |
| 14 | ★ 同一候选多错误维度 | ★ 跨指标错误记录数与唯一候选数**分开报告** | T-15 |

★ ★ **不允许为提高指标自动删除困难候选**：★ 非 strict 模式下未配对项仍计入异常清单；
★ ★ strict 模式下直接 fail-closed。

## 三、★ 独立评估纪律的落实

| 纪律 | 落实方式 |
|---|---|
| ★ 机器预测不读 Gold | ★ 评估器分两个独立列表接收；★ 投影与比对均不修改机器侧字段 |
| ★ 审核者不读机器预测 | ★ 证据包模板只含原文与跨度（★ 见盲审准备文档） |
| ★ 脚本先于正式评分冻结 | ★ 规则版本 `R23-FTP-EVAL-1.0` 已定；★ 正式评分前需冻结其 SHA256 |
| ★ 真实输出暴露后改语义 | ★ 须形成新版本与影响报告，★ 不得静默修改既有预注册 |
