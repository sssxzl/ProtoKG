## 三、追踪结论

★ 链条 **RFC → 抽取候选 → Norm → Fact → 中枢** **完整可追踪**（★ 每步有真实入口）。
★ 链条 **中枢 → 图 → 种子 → 质量验证** 存在**九个断点**（★ A～I）。
★ ★ 其中 **A（跨源对齐）与 B（证据关联）** 是 README 明确声称而产物上不存在的两项。
